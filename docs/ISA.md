# OpenCPU ISA v2

本文件定义当前 RTL、IDE、独立下载器和命令行工具共同使用的指令集。
软件编码表位于 [isa.py](../software/opencpu/core/isa.py)，硬件编码表位于
[isa.vh](../hardware/verilog/include/isa.vh)，两者应与本规范保持一致。
历史工作簿、早期文档和旧图不再定义现行 ISA；旧软件版本可从 Git 历史查看。

## 版本与迁移

v2 不兼容旧机器码。旧程序必须从汇编源或高层源码重新构建，不能通过反汇编旧镜像自动迁移：
旧工具生成的同一编码可能代表不同操作，原意不能仅凭机器码恢复。
旧版软件与机器码已从工作目录清理，历史版本可从 Git 查看；当前源码示例见
[software/examples/README.md](../software/examples/README.md)。

现有 26 个操作码的数字保留，`BLE` 名称统一为严格有符号小于的 `BLT`。
新增 `HALT`、`MRET`、`LUI`、`J`；普通算术立即数字段扩至 8 位；
条件分支和直接跳转改成 PC 相对；访存支持负偏移；`LI` 覆盖旧值，`JAL` 保存真正返回地址。
`0x0000` 是 NOP，不再承担镜像结束、停机或中断返回。

## 程序员模型

- 指令、寄存器和数据字均为 16 位。指令长度固定为一个字；汇编伪指令可以展开为多个字。
- 地址以 **16 位字** 为单位。顺序执行 `PC = PC + 1`，不是加 2 或加 4。
- 地址和算术结果按模 65536 截断。乘法只保留低 16 位，不生成隐含标志。
- `BLT` 采用二进制补码有符号比较；`SRL/SRLI` 为逻辑右移。移位量大于等于 16 时结果为零。
- 复位入口为字地址 0，寄存器和可写 CSR 初值为 0。
- r0 始终读零，写入被丢弃；没有可写的全局条件码寄存器。

| 编号 | 规范名称 | 调用约定 |
|---|---|---|
| r0 | zero | 常数零；兼容别名 `zr`、`s0`，均不可写 |
| r1–r4 | a1–a4 | 参数、临时值，由调用者保存；a1 同时保存返回值 |
| r5 | fp | 帧指针，由被调用者保存；`a5` 是同一寄存器的别名 |
| r6 | ra | 返回地址，非叶函数须保存 |
| r7 | sp | 向低地址增长的栈指针 |

寄存器别名是软件约定，硬件只识别编号。IDE 整数编译器以 sp=1024 初始化栈，
每个变量占一个字；函数最多接收四个参数。r0 不能充当可写的栈帧指针。

## 指令编码

位 0 是最低有效位。所有格式的 `opcode = inst[4:0]`。

| 格式 | 高位字段 | 寄存器字段 | 用途 |
|---|---|---|---|
| R | `[15:11]=0` | rs=`[10:8]`，rd=`[7:5]` | 寄存器算术，两个读操作数含旧 rd |
| I8 | imm8=`[15:8]` | rd=`[7:5]` | 立即数算术、LI/LUI、JAL/JR |
| B5 | signed imm5=`[15:11]` | rs=`[10:8]`，rd=`[7:5]` | 比较后相对跳转 |
| M5 | signed imm5=`[15:11]` | rs=`[10:8]`，rd=`[7:5]` | 基址加偏移访存 |
| C5 | unsigned CSR 地址=`[15:11]` | `[10:8]=0`，rd=`[7:5]` | CSR 读写 |
| J11 | signed imm11=`[15:5]` | 无 | 长相对跳转 |
| S | `[15:5]=0` | 无 | HALT、MRET、RC |

R、C5、S 格式的保留字段必须为零。操作码 14、15 保留。
非法编码不会产生寄存器、内存或 CSR 副作用；当前实现进入 `faulted` 状态，复位后恢复。

下表 `R[d]` 表示寄存器值，`N=PC+1`；除跳转/停机外，执行后 PC=N。
`s8/s5/s11` 分别表示对应字段的符号扩展，`u8/u5` 表示零扩展。
写寄存器和地址计算结果均截断为 16 位。

| 操作码 | 指令 | 格式 | 操作 |
|---|---|---|---|
| 00000 | ADD | R | `R[d] = R[d] + R[s]`；全零字为规范 NOP |
| 00001 | SUB | R | `R[d] = R[d] - R[s]` |
| 00010 | MUL | R | `R[d] = low16(R[d] * R[s])` |
| 00011 | AND | R | `R[d] &= R[s]` |
| 00100 | OR | R | `R[d] \|= R[s]` |
| 00101 | XOR | R | `R[d] ^= R[s]` |
| 00110 | SLL | R | `R[d] <<= R[s]` |
| 00111 | SRL | R | `R[d] = logical_right(R[d], R[s])` |
| 01000 | BEQ | B5 | 相等则 `PC=N+s5` |
| 01001 | BLT | B5 | 有符号小于则 `PC=N+s5`；相等不跳 |
| 01010 | HALT | S | 提交后 PC=N，停止后续执行；仅复位恢复，IRQ 不唤醒 |
| 01011 | MRET | S | 按下述规则返回 mepc 并恢复中断使能 |
| 01100 | LUI | I8 | `R[d] = u8 << 8`，低 8 位清零 |
| 01101 | J | J11 | `PC=N+s11`，不写返回地址 |
| 10000 | ADDI | I8 | `R[d] += s8` |
| 10001 | SUBI | I8 | `R[d] -= s8` |
| 10010 | MULI | I8 | `R[d] = low16(R[d] * s8)` |
| 10011 | ANDI | I8 | `R[d] &= u8` |
| 10100 | ORI | I8 | `R[d] \|= u8` |
| 10101 | XORI | I8 | `R[d] ^= u8` |
| 10110 | SLLI | I8 | `R[d] <<= u8` |
| 10111 | SRLI | I8 | `R[d] = logical_right(R[d], u8)` |
| 11000 | LW | M5 | `R[d] = MEM[R[s]+s5]`，读取一个 16 位字 |
| 11001 | SW | M5 | `MEM[R[s]+s5] = R[d]`，写入一个 16 位字 |
| 11010 | CSRR | C5 | `R[d] = CSR[u5]` |
| 11011 | CSRW | C5 | `CSR[u5] = R[d]` |
| 11100 | JAL | I8 | `R[d]=N; PC=N+s8` |
| 11101 | JR | I8 | `PC=R[d]+s8`，不写返回地址 |
| 11110 | LI | I8 | `R[d]=u8`，覆盖旧值 |
| 11111 | RC | S | 清空全部通用寄存器，包括 fp/ra/sp；不清 CSR |

## 汇编与自动展开

```asm
li a1, 0xabcd           # 伪指令，展开为 LUI a1,0xab / ORI a1,0xcd
addi a1, -1            # signed8，-128..127
sw a1, -1(sp)          # 偏移单位为字，-16..15
csrr a2, 7             # CSR 地址 0..31
beq a1, a2, equal      # 参数是标签或绝对字地址，由汇编器计算相对位移
blt a1, a2, less
call function          # JAL ra,function，距离超范围时自动展开
ret                    # JR ra,0
equal:
    nop
less:
    halt
function:
    ret
```

规范寄存器语法为 `add rd,rs`，立即数语法为 `addi rd,imm`。
兼容旧形式 `add rd,rd,rs`、`add rd,rs,0`、`addi rd,rd,imm`、
`addi rd,zero,imm`，但不会再执行旧工具的负号或 `/4` 转换。
`BLE` 明确报错；需要 `<=` 时应结合 BLT 反向条件和 J 实现。
移位汇编参数限定为 0..15；原始更大移位编码仍按架构规则得到零。

- `LI rd,value` 接受 -32768..65535；0..255 用一个 LI，其余用 LUI+ORI 两个字。
- `LA rd,label` 始终用 LUI+ORI 两个字装载绝对字地址。
- `MOV rd,rs` 用清零和 ADD 实现；同寄存器移动为 NOP，不会破坏原值。
- `CALL label` 等价于 `JAL ra,label`；`RET` 等价于 `JR ra,0`。
- `.word value` 保留一个原始字；反汇编遇到保留编码输出此形式，保证逐字可逆。
- `#`、`;`、`//` 引入行内注释。未知指令、错误操作数、重复/未定义标签和越界立即数会报告源码行号。

条件分支短位移范围为 -16..15 字。超范围时自动展开为：

```text
bcc rd,rs,PC+2   ; 条件成立则执行第三个字
j PC+3           ; 条件不成立则跳过第三个字
j target         ; 长相对跳转
```

JAL 短位移为 -128..127；远调用用 LUI+ORI 将 `PC+3` 写入链接寄存器，再用 J 跳转。
J 的位移为 -1024..1023，足以连接默认 1024 字 ROM 内的任意两个地址。
汇编器迭代布局，标签和 IDE 地址表均按展开后的实际字数计算；超出长跳转范围仍报错。

## 内存与镜像

默认 ROM 和 RAM 各 1024 字（各 2 KiB），空间分离。RAM 为 `0x0000..0x03ff`；
数据访问 `0xff00..0xff5f` 供 LED、按键、开关、数码管、UART、定时器使用，
具体寄存器定义见[硬件说明](../hardware/README.md#mmio-寄存器)。
未映射数据地址读取零、写入忽略；未启用外设的地址同样如此。
没有字节访存指令；8 位协议数据需要软件明确打包，不能沿用旧 32 位栈偏移。

ROM 未装载位置初始化为 HALT，显式装入的零字仍为 NOP。
取指地址超出 ROM 时进入 faulted，错误路径上未提交的越界或非法指令不产生异常。
RAM 上电初始化为零；CPU 复位不要求擦除 RAM。参考模拟器的 Reset 操作同时清空其内存视图。

二进制文本每行一个恰好 16 位的字；UART 下载按每字高字节、低字节的顺序发送。
没有隐式全零结束标记，应在程序中显式写 HALT。CPU 复位保持期间，ROM 下载接口每两个字节写入一个字。
顶层 `ROM_INIT_FILE` 参数可指定 `$readmemb` 镜像，默认空文件名不依赖开发机绝对路径。
串口重载只覆盖本次发送的字，不擦除上次镜像的尾部；需要完全替换时，发送末尾用 HALT
补齐到 1024 字的镜像。仅下载较短程序时，必须确保所有执行路径都在有效范围内结束。
命令行 `assemble` 和 `compile` 的 `--pad-rom` 选项会生成这样的完整镜像。

## CSR 和中断

| 地址 | 名称 | 约定 |
|---|---|---|
| 0 | cycle | 32 位周期计数器低 16 位，只读 |
| 1 | cycleh | 周期计数器高 16 位，只读 |
| 2 | mtvec | 中断入口字地址 |
| 3 | mcause | 本次中断的最低有效 IRQ 位编号，0..7 |
| 4 | mepc | 中断返回字地址 |
| 5 | mie | `[7:0]` 为各 IRQ 使能掩码 |
| 6 | mstatus | bit3=MIE，bit7=MPIE，其余位保留存储 |
| 7 | mscratch | 软件暂存 |

CSR 8..31 读零、写忽略；cycle/cycleh 写忽略。
cycle 是 RTL 物理时钟计数，HALT/fault 后仍计数；参考模型每条执行步骤或显式空闲 tick 加一，不表示流水线周期数。
需要一致的 32 位计数时，可按高/低/高读取并在高位变化时重试。

IRQ 为电平信号；设备必须保持请求到真实提交边界，核不保存短脉冲。
默认顶层 bit0=timer、bit1=UART。顶层用每源一位 pending 将外设脉冲转换为保持到核确认的电平，
包含分支气泡和软件屏蔽期间到达的事件；同源多个事件会合并，不能把中断次数当作事件计数。
实际 IRQ 入口通过 `irq_ack` 确认清除对应 pending；确认与新事件同拍时保留新事件。
多个有效请求取最低编号。只有 `mie` 掩码、MIE 均打开且不在 ISR 内才接受。

1. 当前真实指令先提交，随后用该次提交后的 CSR 值判断 IRQ。因此 CSRW 的使能修改当次即生效。
2. 入口保存 `mepc=当前指令实际 next_pc`。若当前指令是已成立的分支或 JAL，保存跳转目标。
3. 保存 `MPIE=MIE`、清 `MIE=0`，设置 mcause，跳转 mtvec，冲刷年轻指令；不嵌套中断。
4. MRET 跳转 mepc，恢复 `MIE=MPIE`，设置 `MPIE=1`，退出 ISR。
   无特权级限制；MRET 当次不再接收 IRQ，下一条真实指令提交时才重新判断。
5. HALT 优先于 IRQ，执行后仅复位能继续。空操作和流水线气泡不会触发中断返回。

## 实现与验证

当前 RTL 为三级顺序核：F 取指、D 缓存指令、X 译码/读寄存器/执行/提交。
操作数在前一条提交后读取；所有寄存器、CSR、内存、RC、HALT 和 MRET 副作用均由提交有效位控制。
分支和中断冲刷两个年轻槽，没有软件可见的延迟槽。

从仓库根目录执行：

```bash
cd software
python3 -m opencpu assemble examples/simple/isa.asm -o /tmp/isa_v2.bin
python3 -m opencpu run /tmp/isa_v2.bin
cd ..
make -C hardware test
```

当前代码位于 `software/opencpu`，核心、GUI、串口服务与入口分开；所有窗口共用相同的工具链和传输服务。
Verilator testbench 与回归位于 [hardware/common/tb](../hardware/common/tb/README.md)，
需要 Python 3.10+、Verilator、g++ 和 make，无需 Qt 或第三方 Python 测试包。
仿真通过真实 UART RX 引脚装载镜像，构建产物统一放在该目录的 `build/`。
纯 ISA 程序逐提交对照软件模型的 PC、机器字、全部寄存器、可写 CSR 和最终内存；
软件模型也提供 GPIO、UART FIFO、Timer 和中断的确定性 tick 行为，见[软件模拟器](Simulator.md)。
精确 UART、Timer 时序与引脚由整机 RTL 测试检查；不要求物理时钟与模型 tick 相等。
支持 VCD 波形，遇到 fault 或超过周期上限会以非零状态退出。
FPGA 频率和资源需通过实际综合、布局布线确认。
